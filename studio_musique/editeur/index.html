Accord

Chaque voix glisse vers la note de l'accord la plus proche.

Schémas

Couches

Chaque couche est une nouvelle voix qui suit les accords posés (étiquettes violettes sur la règle). Tu peux ensuite la retoucher, la couper ou la supprimer. Si tu changes les accords, supprime la couche et ajoute-la à nouveau.

Batterie

Une ligne = un instrument, 16 cases = une mesure qui se répète. Touche une case pour l'allumer ou l'éteindre. Le tempo se règle dans Réglages.

Réglages

  • Crayon : un toucher = choisir une note (ou une voix) · double toucher = créer une note · faire glisser une note = la déplacer · glisser dans le vide = dessiner une mélodie
  • Sélection : cadre pour choisir plusieurs points · glisser pour les déplacer (Alt = copier)
  • Gomme : toucher ou balayer · Main : déplacer la vue
  • Écouter une voix seule : bouton S de la voix, double-clic sur sa carte en bas, ou double toucher sur sa ligne avec la Sélection ou la Main
  • Deux doigts : se déplacer et pincer pour zoomer (écarter en largeur = temps, en hauteur = notes)
  • Molette : défiler · Maj + molette : avancer dans le temps · Ctrl + molette : zoom · Alt + molette : hauteur des notes
  • Règle : toucher = tête de lecture · glisser = zone de boucle · tirer le drapeau « fin » = durée
  • Clavier à gauche : toucher une touche pour l'entendre, glisser pour monter/descendre
  • Ctrl+Z / Ctrl+Maj+Z annuler/rétablir · Ctrl+C / X / V copier/couper/coller à la tête · Ctrl+D dupliquer · Suppr effacer
  • ↑ ↓ transposer d'un demi-ton (Maj = octave) · ← → décaler d'un pas de grille · Ctrl+A tout choisir
  • Espace lecture · B V E H outils · + − 0 zoom · Ctrl+S enregistrer
