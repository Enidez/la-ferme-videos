> Toute nouvelle session Claude (cloud ou Mac) lit **ce document en entier**, puis **`skill/SKILL.md`** (« la Bible » = la compétence `la-ferme-videos`, qui contient le détail de toutes les règles). Ensuite seulement, elle agit.

## 1. Le projet

**LA FERME** est un média vidéo vertical (9:16) d'actualité française, antisystème mais **factuel** : on prend ce que disent les politiques et les institutions, on le confronte aux faits, et on laisse le spectateur relier les points.

- **Bio / signature** : « Ils parlent à ta place. Nous, on vérifie. »
- **Identité visuelle** : le « **tableau d'enquêteur** » — un mur gris-vert où chaque fait est une carte plastifiée punaisée, reliée par des fils rouges ; une caméra « drone » vole de carte en carte ; tampons rouges, sous-titres courts (3 mots max), grain, ambiance série policière.
- **Ton** : sérieux, tendu, « débrief Canal+ » ; on parle à « toi » ; une thèse d'injustice par vidéo, prouvée par les mots mêmes des puissants.
- **Différence revendiquée** : les autres comptes relaient sans vérifier ; nous, on vérifie — y compris contre notre camp (on démonte les fausses rumeurs).

## 6. Règles d'or (résumé — détail dans la Bible)

1. **Hook dans les 3 premières secondes** : phrase d'intrigue (vraie voix, contradiction, chiffre choc, question). Titre avant ~4 s. Jamais de contexte en ouverture.
2. **Un seul parallèle, frontal, en une phrase** (chiasme) ; liens **implicites** (ne jamais dire « on a relié les points ») ; pas de digressions qui diluent.
3. **Structure numérotée** (étapes / preuves / dossiers) comme LE PLAN.
4. **Faits vérifiés et sourcés** ; ce qui n'est pas prouvé → tampon NON PROUVÉ ; jamais d'accusation non prouvée présentée comme un fait ; présenter honnêtement l'autre version (ex. le procureur).
5. **On démonte aussi les fausses rumeurs**, ton officiel, sans se justifier (« Le parquet dément. »).
6. **Plus de visages et d'émotion** : chaque fait a une photo ou une vraie voix ; images d'illustration étiquetées ; particuliers floutés ; pas de gore ; jamais de mineur blessé.
7. **Les sources/crédits ne dépassent jamais du cadre** de la carte.
8. **Fin** : « Abonne-toi. Ils parlent à ta place. Nous, on vérifie. » (plus jamais « on continue de compter »). Pas de « merci / abonnez-vous » au milieu (post-it muet à la place).
9. **Légendes** : accroche + question en commentaire + ≤ 5 hashtags dont #LaFerme ; **pas de sources ni crédits** dans la légende.
10. **Voix rapide** : pauses minimales.
11. **Aperçu de l'extrait avant tout rendu complet** ; ne jamais refaire une vidéo publiée sans demande.
12. **Durée ≥ 61 s** (monétisation) ; fichier **≤ 30 Mo** pour l'envoi.
13. Ne pas afficher ni nommer les auteurs de commentaires haineux. Ne pas nommer les particuliers (ex. l'étudiante face à Lisnard).
14. Rumeurs graves non sourcées (ex. « un mort dans le jardin de l'Élysée ») : jamais dans un Dossier.

### Fabriquer une vidéo (méthode éprouvée)
1. **Recherche** (WebSearch, agents si gros sujet) → faits sourcés.
2. **Script** (hook d'abord) → validation d'Enidez.
3. **Voix** ElevenLabs (connecteur « creative », flow `ADibhc1EvvuDTkwAUccJ`, modèle `eleven_v3`) : `creative_add_flow_node` → `creative_run_flow_nodes` → `creative_get_flow_run_status` → télécharger `content_url`.
   - **Paul French** `cTNP6ZM2mLTKj2BFhxEh` = voix par défaut des Dossiers (balises `[dramatic] [emphatic] [intense] [firm]`). **Liam** `EmZGlxI7QPvCEMOkFhB9` = voix posée.
   - Resserrer : `silenceremove=start_periods=1:start_threshold=-45dB,silenceremove=stop_periods=-1:stop_duration=0.3:stop_threshold=-42dB:stop_silence=0.18,atempo=1.08-1.12`.
4. **Transcrire** (`tools/transcribe.py`), écrire la liste exacte des phrases (TX), **assembler** la piste (`assemble*.py` : hook, vraies voix, narration) → `proj/audio/vo.wav` + `proj/segs.js` (SEGS / MARK / ID).
5. **Images** : Wikimedia Commons via l'API (crédit + licence), extraits vidéo via `venv/bin/yt-dlp` (courts, cités, floutés, titres trompeurs incrustés floutés).
6. **Tableau** : partir de l'épisode le plus récent (`episodes/15_qui_commande_20oct/`), remplacer cartes / sons / couverture (le `board.js` est assemblé en remplaçant les sections « les cartes », « sons », la couverture).
7. **Planches de contrôle** (`render.py preview`) → corriger chevauchements → **aperçu de l'intro** (`apercu.sh`) → validation → **rendu complet** (`build.sh`, ~15 min pour 2 min 30) → recompresser si > 30 Mo (`b:v = 29*8*1024/durée − 165` k) → couverture JPG → envoi + légende → push du projet sur GitHub.

### Pièges connus
- **Sous-titres** à y ≈ 1 256-1 352 px : sur une carte « plein écran », garder textes et tampons au-dessus de y local ≈ 150.
- **Vue d'ensemble (WIDE)** : utiliser le maintien `WH` (sinon la caméra déborde) et pas de point de recul autour.
- **Sections de musique** : `Tn` = index de la phrase dans SEGS (recompter après assemblage).
- Sur le Mac : certificats (`SSL_CERT_FILE=…/sysca.pem`), dossier temporaire vidé par macOS (toujours travailler dans le dépôt), `rm` avec variables bloqué par sécurité, zsh ne découpe pas les variables (`bash -c`).
- `.mp4` / `.wav` ignorés par git : `git add -f` pour une source indispensable.
- Commits : terminer par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
