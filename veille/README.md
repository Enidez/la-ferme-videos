# Veille — personnalités à suivre (liste d'Enidez)
`personnalites.csv` = base des voix à surveiller pour **repérer les sujets avant tout le monde**.
Méthode (règle de la Bible : la vidéo d'un autre = une idée, jamais une preuve ni un matériau) :
1. Une info repérée chez l'un d'eux = **une piste**.
2. On croise : au moins 2 personnalités de la liste **et** une source primaire (document officiel, déclaration filmée, dépêche AFP/Reuters, chiffres Insee/ONU…).
3. On ne publie que ce que la source primaire confirme ; on cite la source primaire, pas la personnalité.
Ajouter une ligne par nouvelle personnalité (même colonnes). `pistes.csv` (à venir) : date, sujet, qui l'a dit, source primaire trouvée, statut.
